# وصلني WASLNY V12 — نسخة واجهات وتجربة محلية

## التحديثات المنفذة
- واجهتان: البصرة التراثية (افتراضية) والليلي الكحلي/الذهبي، والتبديل من «حسابي» مع حفظ الاختيار على الجهاز.
- خريطة الرئيسية تطلب إذن الموقع وتستخدم watchPosition لتحديث نقطة المستخدم أثناء فتح الرئيسية؛ زر الموقع يعيد التمركز. عند رفض الإذن تبقى خريطة البصرة كخيار احتياطي.
- خريطة تحديد نقطة الانطلاق تحاول البدء من موقع المستخدم الحالي عند السماح.
- تسجيل نوع الحساب (ذكر/أنثى) محليا؛ خيار «كابتن أنثى» يظهر للحساب الأنثوي فقط في شاشة مراجعة الحجز، ويُحفظ كتفضيل في الطلب المحلي.
- ما زالت المسافة والأجرة تعتمد على خدمة المسارات OSRM عند توفر الإنترنت.

## مهم جدا: ما لم يُنفذ بعد
**هذه النسخة ليست نظام حجز تكسي حقيقيا**. الطلبات محفوظة محليا ولا تصل إلى كابتن على جهاز آخر. لا توجد قاعدة بيانات مشتركة أو رسائل SMS OTP أو تحقق من جنس المستخدم أو مصادقة أو تتبع كابتن حقيقي. لا ينبغي التعامل مع خيار «كابتن أنثى» كضمان أو إجراء أمني قبل اعتماد ومراجعة السائقات والتحقق من الحسابات عبر خادم آمن.

لتجربة رحلة بين جهازين نحتاج إعداد Backend آمن (مثلا Supabase)، وتفعيل مزود SMS للتحقق من الأرقام، وجداول الرحلات والكباتن مع RLS وصلاحيات الكابتن والإدارة وتحديثات Realtime. لا تنشر مفاتيح الخدمة السرية في GitHub Pages. لا ترفع مستمسكات هوية حقيقية للموقع الثابت.
