# وصلني WASLNY — V10 (واجهة الخريطة والإعلانات)

واجهة الزبون: خريطة OpenStreetMap تظهر مباشرة بعد التسجيل التجريبي، حقول الانطلاق والوجهة، إعلان في الرئيسية، شريط تنقل (الرئيسية، رحلاتي، المحفظة، حسابي). حجز الرحلة يستخدم واجهة V9 وحساب الطريق عبر OSRM عند توفر الإنترنت.

## النشر على GitHub Pages
1. فك ضغط ZIP.
2. ارفع **جميع الملفات داخل المجلد** إلى جذر مستودع Waslny على فرع main، مع استبدال الملفات القديمة. لا ترفع ملف ZIP وحده.
3. انتظر نجاح GitHub Pages ثم افتح https://waslny-basra.github.io/Waslny/?v=10
4. إذا بقيت واجهة قديمة، افتح الرابط في نافذة خاصة أو امسح بيانات الموقع؛ أزلنا تسجيل Service Worker في V10 حتى لا يثبت الإصدار القديم.

## تنبيه أمني
هذه واجهة تجريبية فقط. لا يوجد خادم ولا ربط بين أجهزة الزبائن والكباتن والإدارة. لا تضع بيانات شخصية حقيقية أو مستمسكات أو معلومات بطاقات دفع. المحفظة لا تشحن رصيدا ولا تحفظ بيانات بطاقة، والإعلانات أماكن محجوزة حتى ربط لوحة إدارة آمنة. لوحة الإدارة الموجودة غير محمية، ولا يجوز استخدامها للإدارة الحقيقية.

تُستخدم خرائط OpenStreetMap وLeaflet وOSRM العامة للتجربة، وتحتاج إعداد خدمة خرائط ومسارات مناسبة قبل إطلاق التطبيق تجاريا.
