# وصلني WASLNY — V5

واجهة حجز جديدة مستوحاة من تسلسل الحجز المعروض في المراجع: الرئيسية ← اختيار الانطلاق ← الوجهة ← مسار الطريق والأجرة ← فئة السيارة ← شاشة الطلب التجريبي.

التطبيق يحسب الأجرة آليا عبر OSRM؛ لا توجد حقول لإدخال الأجرة أو المسافة. يمكن إضافة حتى ثلاث نقاط توقف.

**تنبيه:** الطلبات محلية ولا تصل إلى الكباتن؛ لا يوجد نظام حسابات محمي أو قاعدة بيانات أو إرسال مستمسكات. الأسعار تجريبية وليست أسعار تطبيق كفو. لا تستخدم هذه النسخة للتشغيل الحقيقي.


## V6 — تسجيل الزبون التجريبي والدعم
- نموذج اسم ورقم هاتف ومنطقة وملاحظة للزبون، يعرض قبل بدء الحجز، ويحفظ محليا فقط.
- شاشة حسابي تتيح تعديل البيانات التجريبية.
- سجل الإدارة يعرض بيانات زبون تجريبي إذا كان على الجهاز نفسه فقط.
- صفحة support.html تتيح التواصل عبر رقم واتساب الإدارة السابق، وليست قناة دعم مستقلة.
- **لا توجد مصادقة أو قاعدة بيانات أو مشاركة مع الكابتن/الإدارة**. لا تستخدم بيانات شخصية حقيقية أو مستمسكات قبل بناء خادم آمن وصلاحيات وتخزين خاص.


## V7 — التسجيل قبل الحجز
- شاشة تسجيل الزبون تظهر أولا عند عدم وجود ملف محفوظ على الجهاز.
- لا يمكن تجاوز التسجيل إلى الصفحة الرئيسية أو الحجز دون ملف زبون تجريبي.
- بعد الحفظ ينتقل الزبون للرئيسية، وعند العودة يستخدم الملف المحلي السابق.
- هذا ليس تسجيل دخول موثقا ولا يرسل المعلومات للكابتن أو الإدارة؛ يتطلب ذلك خادما آمنا.


## V8 — لوحة إحصائيات الإدارة
أربع بطاقات: الكباتن المتاحون، طلبات الرحلات، الزبائن المسجلون، الكباتن المسجلون. الطلبات والزبائن تحسب محليا على الجهاز فقط؛ إحصاءات الكباتن تظهر (—) إلى حين ربط خادم آمن. لا تُعرض أرقام مختلقة على أنها أرقام حقيقية.

| بلس | 2000 | 550 | 45 | 4000 |

الأجرة = تقريب لأعلى 250 دينارا لـ max(الحد الأدنى، فتح العداد + الكيلومترات × سعر الكيلومتر + الدقائق × سعر الدقيقة). الأسعار أولية، وتظهر بعد حساب المسار من خدمة المسارات. لا يدخل الزبون المسافة أو السعر. يمكن تعديل الفئات من لوحة الإدارة **على نفس الجهاز فقط**. لن تصل إعدادات الإدارة إلى هواتف الزبائن حتى تُربط قاعدة بيانات وخادم محمي. لا توجد عمولة لكل رحلة في نموذج الاشتراك المقترح (75 ألف دينار / 30 يوما)، وهو قرار تجاري قابل للمراجعة.
