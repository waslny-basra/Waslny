# وصلني WASLNY V11 — واجهة الزبون الجديدة

نسخة V11 تعيد تصميم الواجهة الرئيسية بالهوية الزرقاء والذهبية، وتعرض خريطة البصرة فور الدخول بعد التسجيل التجريبي، وحجز الرحلة، ومساحة للإعلانات، والاختصارات، وشريط التنقل بأربعة أقسام.

## الرفع إلى GitHub Pages
ارفع **الملفات المفكوكة داخل هذا المجلد** إلى جذر فرع `main` في `waslny-basra/Waslny`، واستبدل الملفات الموجودة. لا ترفع ZIP وحده.

## حدود النسخة
هذه واجهة تجريبية، ولا ترسل الطلبات إلى الكباتن أو الإدارة. تسجيل الزبون محلي على نفس الجهاز. المحفظة والدفع غير مفعلين، ولا ينبغي إدخال بطاقات أو وثائق شخصية حقيقية. الخريطة تستخدم Leaflet/OpenStreetMap عبر الإنترنت. تصميم الرأس بصري مبني على الألوان والرموز، ولا يستخدم صورا مولدة أو صورا فوتوغرافية غير مرخصة. يمكن إضافة صور البصرة الحقيقية بعد توفير مصدر وترخيص مناسبين.

ملاحظة: إذا كانت النسخة القديمة تظهر، امسح بيانات الموقع أو افتح نافذة خاصة؛ لأن المتصفح قد يحتفظ بملفات الخدمة القديمة.
