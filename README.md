# وصلني WASLNY — V5

واجهة حجز جديدة مستوحاة من تسلسل الحجز المعروض في المراجع: الرئيسية ← اختيار الانطلاق ← الوجهة ← مسار الطريق والأجرة ← فئة السيارة ← شاشة الطلب التجريبي.

التطبيق يحسب الأجرة آليا عبر OSRM؛ لا توجد حقول لإدخال الأجرة أو المسافة. يمكن إضافة حتى ثلاث نقاط توقف.

**تنبيه:** الطلبات محلية ولا تصل إلى الكباتن؛ لا يوجد نظام حسابات محمي أو قاعدة بيانات أو إرسال مستمسكات. الأسعار تجريبية وليست أسعار تطبيق كفو. لا تستخدم هذه النسخة للتشغيل الحقيقي.


## V6 — تسجيل الزبون التجريبي والدعم
- نموذج اسم ورقم هاتف ومنطقة وملاحظة للزبون، يعرض قبل بدء الحجز، ويحفظ محليا فقط.
- شاشة حسابي تتيح تعديل البيانات التجريبية.
- سجل الإدارة يعرض بيانات زبون تجريبي إذا كان على الجهاز نفسه فقط.
- صفحة support.html تتيح التواصل عبر رقم واتساب الإدارة السابق، وليست قناة دعم مستقلة.
- **لا توجد مصادقة أو قاعدة بيانات أو مشاركة مع الكابتن/الإدارة**. لا تستخدم بيانات شخصية حقيقية أو مستمسكات قبل بناء خادم آمن وصلاحيات وتخزين خاص.
