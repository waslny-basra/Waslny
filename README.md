# وصلني V13 — إعادة بناء الواجهة

- واجهة الزبون الرئيسية بتصميم البصرة التراثية (افتراضي) وتصميم ليلي كحلي/ذهبي من حسابي.
- الخريطة من OpenStreetMap وLeaflet، تستخدم إذن موقع الجهاز عند الموافقة، وتحدث العلامة أثناء فتح الصفحة.
- حجز تجريبي محلي، بدون اتصال بين هاتف الزبون والكابتن.
- لا يوجد OTP حقيقي أو قاعدة بيانات أو مدفوعات حقيقية. لا تدخل معلومات أو وثائق حساسة.
- صور التصميم المرجعي لم تُنسخ حرفيا، بل أعيد تنفيذ الترتيب والتصميم بواجهة HTML/CSS قابلة للاستخدام.

ارفع محتويات ZIP مباشرة إلى جذر مستودع GitHub Pages، ثم انتظر النشر وافتح نافذة خاصة إذا بقيت نسخة قديمة في الكاش.
