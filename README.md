# وصلني WASALNI — النسخة التجريبية الثانية

الصفحات: `customer.html` للزبون، `driver.html` للكابتن، `admin.html` للإدارة. صفحة `index.html` تحوّل للزبون.

## الجديد
- خريطة البصرة باستخدام Leaflet وOpenStreetMap، تحتاج إنترنت.
- فئات توفير وسوبر وبلس، وحاسبة أجرة تجريبية حسب المسافة والمدة المدخلتين يدويا.
- إعدادات التسعير محليا في لوحة الإدارة، وكود خصم ومكافآت كباتن كأقسام غير مفعلة.
- استمارة تسجيل أولية للكابتن، وإرسال الاسم والهاتف والسيارة والفئة عبر رابط واتساب إلى +96598056128.
- اشتراك معلن 75,000 د.ع / 30 يوما عبر زين كاش 07710859123.
