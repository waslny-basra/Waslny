# وصلني V15 — إعادة بناء واجهة الزبون

## ما يعمل الآن
- واجهة داكنة كحلية وذهبية تحاكي مرجع المستخدم، وواجهة فاتحة مستوحاة من البصرة؛ التبديل من الإعدادات محفوظ محليا.
- شاشة التسجيل التجريبي، اختيار الجنس، وإظهار خيار كابتن أنثى في واجهة الراكبات فقط (غير موثق الهوية).
- خريطة Leaflet/OpenStreetMap؛ موقع حي بعد الإذن، تحديث أثناء استخدام الصفحة، تحديد الانطلاق والوجهة بالنقر.
- اختيار نوع السيارة، طلب تجريبي محفوظ على نفس الجهاز، رحلاتي، حسابي، محفظة تجريبية، مساحة إعلانية.
- ملفات الزبون index.html وcustomer.html تستخدم الواجهة الجديدة؛ صفحات driver/admin/support من V14 محفوظة للتوافق.

## غير موجود بعد — لا تدّعِ تشغيله
- لا SMS OTP فعلي؛ الحساب محلي وغير موثق.
- لا قاعدة بيانات مشتركة أو مطابقة كباتن أو إرسال طلب بين جهازين أو تتبع كابتن أو دفع.
- لا تسعير واقعي أو اختيار كابتن أنثى محقق الهوية.
- صور الجسر والتراث رسوم SVG وليست صورا فوتوغرافية حقيقية. تحتاج صور مرخصة قبل استبدالها.

## النشر
فك ضغط ZIP وارفع محتويات المجلد (وليس المجلد نفسه) إلى جذر مستودع GitHub Pages. ملف index.html هو نقطة الدخول. النسخة تتطلب إنترنت لخرائط OpenStreetMap وLeaflet.

## الأمان
لا تضع رموز مزود SMS أو مفاتيح service-role أو مستمسكات السائقين في GitHub Pages. لتفعيل الإنتاج: خادم آمن، Supabase Auth أو مزود OTP موثوق، سياسات RLS، مخزن خاص للمستمسكات، واشتراط تحقق فعلي للسائقات.
